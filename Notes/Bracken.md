# Bracken

## Описание

Вероятностный инструмент для уточнения таксономического профилирования Kraken. Решает проблему субоптимальной точности Kraken на низких таксономических уровнях.

## Принцип работы

- Вероятностное переназначение ридов по таксономическому дереву
- Улучшение точности на уровне вида и ниже

## Входные данные

- Результаты классификации Kraken
- База данных Kraken

## Выходные данные

- Уточнённый таксономический профиль с оценками обилий
