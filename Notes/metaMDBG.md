# metaMDBG

## Описание

Ассемблер для высококачественных длинных ридов, строящий сборку вокруг minimizers.

## Принцип работы

- Использует minimizers (стратегия суммирования геномных данных) вместо полных de Bruijn graph
- Преимущества: скорость и экономия памяти

## Что такое minimizers

Подмножество k-меров, выбранное для компактного представления последовательностей при сохранении информации о сходстве. Подробнее: [[Minimizers]]

## Входные данные

- Высококачественные long-read риды (HiFi)

## Выходные данные

- FASTA файлы контигов
