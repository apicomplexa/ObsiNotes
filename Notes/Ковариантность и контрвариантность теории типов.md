# Ковариантность

> [!$] Тип-конструктор __ковариантен__ по параметру `T`, если допустима замена `T` на его подтип `T_sub` без нарушения типобезопасности
> __Формально__ `T_sub <: T ⇒ F<T_sub> <: F<T>` _(Если `T_sub` - подтип `T`, то F от T_sub - подтип F от T)_

Возможно только если тип T используется только на выходе

```TypeScript
interface Animal { kind: string }
interface Dog extends Animal { bark: () => void }

interface Producer<T> {
  get(): T     // T используется только на выходе → ковариантность
}

const dogProducer: Producer<Dog> = {
  get: () => ({ kind: "dog", bark: () => {} })
}

const animalProducer: Producer<Animal> = dogProducer // OK: Dog <: Animal
```

> [!$]- Пример
> Если Кот подтип Животное. Стая(Котов) подтип Стая(Животных) если Стая() это ковариантный конструктор. То везде где мне нужна стая животных я могу использовать стаю котов

# Контрвариантность

> [!$] Тип-конструктор __контравариантен__ по параметру `T`, если допустима замена `T` на его __надтип__ `T_super`
> __Формально__ `T_sub <: T ⇒ F<T> <: F<T_sub>`

```TypeScript
interface Animal { kind: string }
interface Dog extends Animal { bark: () => void }

interface Consumer<T> {
  put(value: T): void    // T только вход → контравариантность
}

const animalConsumer: Consumer<Animal> = {
  put: (a) => console.log(a.kind)
}

// Можно подставить Consumer<Animal> туда, где нужен Consumer<Dog>
const dogConsumer: Consumer<Dog> = animalConsumer // OK
```

> [!$]- Пример
> Если я хочу погладить Кота я могу использовать для этого функцию Погладить(Животное), и это будет контрвариантность
