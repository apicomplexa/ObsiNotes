# CAGE–метод

## CAGE–метод

- позволяет увеличить покрытие `5'` конца
- в основном для анализа коротких регуляторных последовательности (н.п. [[eRNA]])
	![[Pasted image 20230105210436.png]]

### Последовательность:

1. Обратная транскрипция
2. Биотинилирование `CAP` на `3'` конце ==РНК==
3. При помощи [[RNase ONE]] расщепляем РНК, несцепленные с ДНК ⇒ те в которых RT не дошло до конца
4. За биотин вытаскиваем ⇒ вытаскивается только та ДНК, которая насинтезировалась до `5'`
