# MetaBAT

## Описание

Эффективный инструмент для точной реконструкции отдельных геномов из сложных микробных сообществ методом биннинга контигов.

## Принцип работы

- Модифицированный k-medoid алгоритм кластеризации
- Метрика расстояния: тетрамерное сходство + информация об обилии

## Входные данные

- FASTA файлы контигов
- BAM файлы (для информации о покрытии)

## Выходные данные

- Бины (папки с FASTA файлами контигов)

## Применение

- Биннинг метагеномных контигов → получение MAGs
