# COG (Clusters of Orthologous Groups)

## Описание

База данных кластеров ортологичных групп генов, классифицирующая гены по эволюционно связанным группам для предсказания функций.

## Применение

- Функциональная аннотация через [[eggNOG-mapper]]
- Классификация генов по функциональным категориям

## Связанные концепты

- [[KEGG]]
- [[eggNOG-mapper]]
- [[Функциональная аннотация метагенома]]
