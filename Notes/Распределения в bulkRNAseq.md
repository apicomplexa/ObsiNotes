# Пуассон

Если сослаться на [[Центральная Предельная Теорема|ЦПТ]], то можно сказать что данные распределены нормально

==Но==

- Значения всегда больше 0
- Значения дискретные

> [!$] Тогда можно воспользоваться [[Распределение Пуассона|распределением Пуассона]]

![[Распределение Пуассона#^00de6f]]

==Но==

- Есть биологический статистический шум
- Шум на уровне подготовки библиотеки

> [!$] Поэтому дисперсия будет _больше чем в Пуассоне_

# Отрицательное биномиальное распределение

[[Отрицательное биномиальное распределение]]

Считаем число удач

![[Отрицательное биномиальное распределение#^fe47e8]]![[Отрицательное биномиальное распределение#^97dafd]]

- Допустим, берем 1 рид из образца __X__
- Если прочтение из гена ___g___ то это успех (⇒ число успехов = кол-во каунтов гена)
- Если нет, то неудача (число неудач = глубина секвенирования)
- ==p – вероятность успеха = экспрессия гена==

# Как понять какое распределение

- Попытаться построить график взаимодействия среднего и дисперсии (и увидеть н.п. овердисперсию для NBD)
- Также строят вместо него можно график ==биологической ковариации==
- Важно понимать, что каунты разных генов могут быть распределены по разному

## Статистический пайплайн

1. Допустим, что значения описываются распределением $X(a, b)$
2. При помощи [[Maximul likelihood estimation|MLE]] подбираем параметры распределения так, чтобы произведение правдоподобий для всех точек было максимальным.
3. После можно посчитать правдоподобие, что данные порождены эти распределением с этими параметрами
4. А теперь можно сравнить с другими распределениями
5. Но максимальное правдоподобие будет иметь распределение с большим кол-во мод и др параметров (из-за шума данных)
6. Поэтому сравнивают правдоподобия нормированные на кол-во параметров распределения (`Goodness of fitness`)
