# Задача

> [!$] Необходимо сравнить среднее экспрессий между 2 выборками

## Стандартное решение не подходит:

- ==t-test== – распределение не нормальное
- ==Тест Манна-Уитни== – слишком слабый и дает ошибки на маленьких выборках (а в случае секвенирования выборки очень маленькие)

# [[Регрессионный анализ]]

Предположим, что экспрессия изменяется от возраста, тогда можно построить регрессионную прямую:

![[Pasted image 20230731174117.png]]

А теперь предположим, что возраст это дискретная величина: молодые и старые.

Тогда можно построить линию регрессии на дискретных данных:

$expr = \beta_1\cdot young + \beta_2\cdot old$

![[Pasted image 20230731174534.png]]

> [!$] Отличаются ли $\beta_1$ и $\beta_2$ (≡ значима ли разница)

Т.е. мы как бы сдвигаем оси в центр одного из распределений – и отмеряем отличия от него, а не гипотетического 0.

Т.е. все равно что при сравнении цен на квартиры в разных районах города сравниваем не относительно 0, а н.п. относительно цен в районе_1 (н.п. = 5 у.е.) примем это за 0. В районе_2 больше на 1 у.е. А в районе_3 больше на 2 у.е. Значит в районе_3 квартиры дороже

## Проблемы

> [!$] Распределения зависимой переменной в каждом случае должно быть нормальным и одинаковыми дисперсиями (см. [[Регрессионный анализ#Условия|условия применения линейной регрессии]])

А у нас [[Отрицательное биномиальное распределение|NBD]], а еще и ==чем больше экспрессия, тем больше дисперсия значений==

# Проблема с ложно-положительными

> [!$] Чем больше будет сравниваться образцов, тем большее количество DE генов будет появляться.

Это происходит потому, что чем больше образцов в каждой выборке, тем сложнее гарантировать, что эти выборки будут отличаться __исключительно__ исследуемым параметром:

- Нп. `cancer vs normal`
- И тут как с маленькими `p-value` могут быть гены, которые н.п. из-за SNP стали DE или н.п. из-за возраста (н.п. потому что с раком больше старых людей) и тд

> [!$] Решение - использовать оценку по `logFoldChange`

# Идеальный шаблон

1. Прогоняем kallisto (быстро, дешево, сердито)
2. При помощи [[tximport]] приводим транскрипты на длину
3. Запускаем на приведенных данный [[DEseq2 (RLE)|DEseq2]] (или [[edgeR]])

## Пример:

> 16 сэмплов:
> - Мыши ДТ + Нокаут

### Tximport

```R
txdb <- EnsDb.Mmusculus.v79  # Просто ярлык для БД анотаций мыши
tx2gene <- transcripts(txdb, return.type="DataFrame")
tx2gene <- tx2gene[c("tx_id", "gene_id")]

# Далее просто ярлыки для файлов псеводовыравнивания
samples <- str_c(c(str_c("wt_water_",c(1,2,3,4)),         # дикий тип, поили водой

                   str_c("ko_bicarb_",c(1,2,3,4))),".sf") # нокут бикарбонат

files <- str_c("data/samples/", samples)
head(tx2gene)
```

### Загружаю данные в DeSeq

```R
dds <- DESeqDataSetFromTximport(
  txi,
  colData = samples,
  design = ~ knock + treat + knock * treat
)
```

### Фильтрую белок кодирующие гены

```R
biomart <- read.csv('./data/mouse_mart.csv')

geneType <- biomart$Gene.type[match(rownames(counts(dds)), biomart$Gene.stable.ID)]
typeFilter <- geneType == 'protein_coding'
typeFilter[is.na(typeFilter)] <- FALSE

dds <- dds[typeFilter,]
```
