# Выборочное стандартное отклонение

$$
s = \sqrt \frac {\Sigma (X - \overline X)^2} {n - 1}
$$

Где:

$\overline X$ — среднее выборочное

$n$ — размер выборки

в numpy — `np.std(ddof=1)`

# Стандартная ошибка среднего

С какой точностью среднее выборки характеризует среднее всей совокупности

по любой выборке размером $n$ из совокупности с std = $\sigma$

$$
\sigma _{\overline X}=\frac {\sigma} {\sqrt n  }
$$

Собственно с.о.с

оценка $\sigma _{\overline X}$ по 1 выборке

$$
s _{\overline X}=\frac {s} {\sqrt n  }
$$
