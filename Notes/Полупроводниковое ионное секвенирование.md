# Раздел: [[NGS-2 Машинное секвенирование]]

# Полупроводниковое ионное секвенирование

- Длина ридов: до сотен килобаз (ultra-long reads)
- Частота ошибок: 4–10% (выше, чем Illumina)
- Real-time acquisition
- Прямое секвенирование нативной ДНК (без амплификации → нет PCR-смещений, сохраняются эпигенетические модификации)
