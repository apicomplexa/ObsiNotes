# Задание моделей

Для указания что одна переменная зависит от другой используют знак `~`

```R
y ~ x
```

Если на зависимую переменную влияют более 1 независимой, то соединяем их через `+`

```R
y ~ x_1 + x_2 
```

Если влияние переменной `x_1` зависит от переменной `x_2` используют `:`

```R
y ~ x_1:x_2
```

Главные эффекты + взаимодействие – `*`

```R
y ~ x_1 + x_2 + x_1:x_2
===
y ~ x_1 * x_2
```

Можно указать степень взаимодействия через `(…)^n` – т.е. добавить взаимодействия до уровня n

```R
y ~ (x1 + x2 + x3)^2
===
y ~ x1+x2+x3 + x1:x2 + x1:x3 + x2:x3
```

Повторные измерения

```R
y ~ x + Error(subject/x)
```
