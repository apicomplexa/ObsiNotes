# Oligo (dT) – гибридизация

- через poly-A хвост
- Магнитная частица с олигонк из Тиминов ⇒ к ним присоединяются poly-A хвосты РНК (рРНК и тРНК не полиаденилируются, что круто)
- но некоторые интересные РНК тоже без поли-А

# Деплеция РНК

- Можно получить не поли-А транскрипты

1. `+` ДНК, комплиментарная рибосомальной РНК
	- ![[Pasted image 20221231231842.png]]
2. `–`–ДНК-РНК комплексы
	- при помощи [Ribonuclease H](https://en.wikipedia.org/wiki/Ribonuclease_H)
3. Удаление ДНК из пробы
	- [Deoxyribonuclease I](https://en.wikipedia.org/wiki/Deoxyribonuclease_I)
