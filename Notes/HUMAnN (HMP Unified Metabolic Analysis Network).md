# HUMAnN (HMP Unified Metabolic Analysis Network)

## Описание

Аннотирует и реконструирует метаболические пути человека путём маппинга секвенирующих ридов к референсным генам или белковым семействам известных функциональных путей.

## Принцип работы

1. Маппинг ридов к нуклеотидным референсным базам
2. Трансляционный поиск для нераспознанных ридов
3. Реконструкция метаболических путей
4. Количественная оценка путей и генных семейств

## Входные данные

- FASTQ файлы (после QC)

## Выходные данные

- Профили генных семейств
- Профили метаболических путей

## Применение

- Функциональное профилирование микробиома кишечника
- Изучение экологических и биогеохимических функций микробиота-хозяин
