  Численная мера несоответствия двух строк (равной длине) равная количеству посимвольных несовпадений (_мисматчей_)

  __Формально__

  Для строк $p$ и $q$: $p_1, p_2,...p_k$, $q_1, q_2, ... q_k$, _мисматчем_ называется $p_i \neq q_i$. Тогда $Hamming Distance(p, q)$ - общее количество мисматчей

# Реализация

```python
def hd(s1, s2):
	return(sum(sb1!=sb2 for sb1, sb2 in zip(s1, s2)))
```
