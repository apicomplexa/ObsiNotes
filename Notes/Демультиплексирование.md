# Демультиплексирование

## Описание

Разделение секвенирующих ридов по отдельным образцам на основе уникальных индексов (баркодов), встроенных в риды при подготовке библиотек.

## Принцип работы

1. Считывание индексной последовательности каждого рида
2. Сопоставление с metadata-файлом (индекс → образец)
3. Распределение ридов по файлам образцов

## Инструменты

- [[Flexbar]] — параллелизация через SIMD и многоядерность
- [[Ultraplex]] — быстрый, гибкий демультиплексер

## Дизайн индексов

Индексы должны проектироваться с использованием error-correcting методов для минимизации неправильного присвоения ридов из-за ошибок секвенирования:

- [[CD-HIT]]
- [[DNACLUST]]
- [[Shepherd]]
