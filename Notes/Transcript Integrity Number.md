# Transcript Integrity Number

- преобразует [[Gen Body Coverage|GBC]] в численный показатель от 1 до 100

|            | ==TIN== |
| ---------- | :-----: |
| ==FF-1==   |   72    |
| ==FFPE-1== |   23    |
| ==FF-2==   |   72    |
| ==FFPE-2== |    1    |

- TIN точнее RIN, есть корреляция, но TIN=100 ≠ RIN=10
