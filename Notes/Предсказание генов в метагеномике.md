# Предсказание генов в метагеномике

## Описание

Идентификация потенциальных белок-кодирующих генов из метагеномных ридов или контигов. Ключевая сложность — наличие фрагментарных (неполных) ORF в метагеномных данных.

## Подходы

### Alignment-based (ранние методы)

- [[CRITICA]] — сравнение с известными белковыми базами
- [[Orpheus]] — то же
- Ограничение: определяют только ранее охарактеризованные гены

### Ab initio (статистические модели)

Обучаются на известных последовательностях генов, анализируют:

- Частоты k-меров
- Длину ORF
- GC-содержание
- Последовательностные мотивы (ribosomal binding sites, di-codon usage)

Методы:

- Hidden Markov models
- Support vector machines
- Conditional random fields

### Deep learning

- [[CNN-MGP]] — convolutional neural networks
- [[Meta-MFDL]]

## Инструменты

| Инструмент | Подход | Особенности |
|-----------|--------|------------|
| [[MetaGeneAnnotator]] | Ab initio | Species-specific: паттерны ribosomal binding sites, di-codon usage |
| [[Prodigal]] | Ab initio | Start codon, RBS motifs, GC-content, hexamer usage |
| [[CNN-MGP]] | Deep learning | CNN для метагеномики |
| [[Meta-MFDL]] | Deep learning | — |
| [[MetaErg]] | Ab initio + | Дополнительные признаки: signal peptides, transmembrane helices |

## Ограничения

- Нет единого золотого стандарта
- Ab initio превосходят evidence-based в общем случае, но результаты варьируют по организмам
- Параметры моделей различаются между видами бактерий
