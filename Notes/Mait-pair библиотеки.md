# Зачем

Иллюмина не получает [[Paired-end reads]] для ==.>750пн==

Поэтому ==для ориентации далеко расположенных контигов== используют mait-pair библиотеки

# Технология

- [b] ==Схема создания m-p библиотеки==
	![[Pasted image 20230316123210.png]]

1. Длинные фрагменты (2-5к пн) помечаются ==биотином==
2. ==Замыкание нк в кольцо==
3. ==Фрагментация== кольца
4. За биотин вытаскиваем участок который содержит по разные стороны от биотиновой метки участки с ==разных концов длинной нк==
5. Секвенирование этого фрагмента
6. Т.о. ==ориентация далекорасположенных фрагментов==
