# Публичные репозитории метагеномных данных

## Описание

Публичные репозитории — жизненно важный ресурс для распространения метагеномных данных и обеспечения воспроизводимости исследований.

## Основные репозитории

| База данных | Примерное число образцов | Описание |
|------------|------------------------|----------|
| ENA/SRA | ~2,000,000 | Крупнейший публичный репозиторий метагеномных данных |
| MGnify | ~343,000 | Гармонизированный анализ, хранение и межисследовательские ассоциации |
| MG-RAST | ~512,000 | Автоматический анализ при загрузке (не поддерживается активно) |
| Tara Oceans | ~35,000 | Морские образцы (210 океанских станций) |

## Проблемы использования данных

- Неполнота метаданных
- Высокие вычислительные требования для сырых данных
- Неравенство в генерации данных

## Meta-analyses

- Агрегация нескольких исследований — мощный подход для новых открытий
- Применения: здоровье человека, микробная экология, вирусология, drug targets

## Cloud-based платформы

- [[MGnify]] — автоматические пайплайны
- NCBI Cloud Resources
- Galaxy Project — web-интерфейс без программирования
- CyVerse — интегрированная киберинфраструктура

## Стандарты метаданных

- BioProject и BioSample (NCBI)
- Genomic Standards Consortium
- MIMARKS, MIxS спецификации
