# Описание

> [!$] Линейно проходимся по массиву элементов (вчт строке) длины $N$ и на каждом $i$-том шаге смотрим только на $n$ элементов - от $i$ до $i+n$

# Для чего нужно

1. Расчет вхождений подстроки в строку. Н.п. поиск k-меров в геноме
2. Поиска скрытых паттернов в геноме (через частоты к-меров и неравномерности их распределения (см [[#Двойной|двойное СО]]))

# Реализации

## Классический

```python
def sliding_window_generator(string: str, sw_length: int):
	"""
	Генератор скользящего окна по строке с заданным размером
	time O(sw_length) - создание среза (через копирование) на каждый шаг
	space O(1)
	"""
    return map(
	    lambda start: string[start:start+sw_length],
	    range(0, len(string)-sw_length+1)
	)
```

Можно добавить счетчик и н.п. посчитать количество кмеров

## Двойной

Можно совместить с двумя указателями, и тогда два скользящих окна будут ограничивать, бОльшее скользящее окно

Тогда ведущее скользящее окно будет увеличивать счетчик большого окна, а отстающее окно будет уменьшать

Нужно если задача двойного скользящего окна н.п. посчитать плотность распределения какой то подстроки в рамках н.п. каждые 500 символов

```python
counts = defaultdict(int)
kmers = set()

# Инициализирую большое скользящее окно длинны L 
for sw in sliding_window_generator(genome[:L], k):
    counts[sw] += 1
    if counts[sw] >= t:
        book_kmers.add(sw)
last_kmer = sw

# для скользящих окна, оба сдвигаются синхронно
for last_kmer, new_kmer in zip(
    sliding_window_generator(genome[1:], k), # Первый - на конце большого СО
    sliding_window_generator(genome[L+1:], k) # Второй - перед большим СО
):

    counts[new_kmer] += 1 # Увеличиваю счетчик по новому кмеру, входящему в большое СО
    counts[last_kmer] -= 1 # Уменьшаем счетчик кмера, который вышел из строки
    if counts[new_kmer] >= t:
        kmers.add(new_kmer) # Если параметры большого СО удовлетворяют нащим условиям (здесь плотность кмера в большом СО) то сохраняем результат
```

И тогда можно определить аномальные частотные зоны, н.п. скопения кмеров
