# Kraken

## Описание

Ультрабыстрый инструмент таксономической классификации метагеномных последовательностей с использованием точного k-mer matching. Первый метод классификации всех ридов метагеномного образца (2014).

## Принцип работы

- Каждый k-мер запроса сопоставляется с k-мерами референсной базы
- LCA геномов, содержащих k-мер → таксономическое присвоение
- Majority vote стратегия для классификации рида

## Входные данные

- FASTQ/FASTA файлы
- Референсная база данных Kraken

## Выходные данные

- Файл классификаций (каждый рид → таксон)
- Отчёт с относительными обилиями

## Ограничения

- Проблемы с точностью на низких таксономических уровнях из-за высокого сходства последовательностей и ошибок секвенирования
- Решение: [[Bracken]] для улучшения разрешения
