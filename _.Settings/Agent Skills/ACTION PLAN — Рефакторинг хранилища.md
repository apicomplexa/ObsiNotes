Создать `_. Home/Bases/Projects.base` — таблица/карточки для навигации по проектным заметкам.

Предлагаемая структура:

```yaml
views:
  - type: table
    name: Истории болезней
    filters:
      and:
        - file.folder: "Projects/Истории болезней"
    order: [file.name, date, summary, tags]
    sort:
      - property: date
        direction: DESC
  - type: table
    name: Статьи и рефераты
    filters:
      and:
        - file.folder: "Projects/Статьи и рефераты"
    order: [file.name, date, summary]
    sort:
      - property: date
```
