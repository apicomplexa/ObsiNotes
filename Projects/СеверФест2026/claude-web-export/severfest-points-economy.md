# Экономика баллов

← [[00-severfest-moc|Северфест — MOC]]

## Актуальная версия — v2 (заменяет v1)

Общая экономика: __Σ = 200 баллов__, разбито на Образование 92 / Развлечение 108.

### Образование — 92

- Командная игра-проект: 30 баллов каждому участнику команды-победителя (I место — 30, II — 23, III — 18, остальные команды — 10)
- 6 блоков направлений по 7 баллов = 42 (3 за вопрос + 2 за посещаемость + 2 "что-то ещё")
- Общий блок — 20 (10 за групповое фото + 2 за посещаемость + 6 за вопрос + 2 другое)

### Развлечение — 108

- 3 программных блока — 11 / 9 / 7 / 5 по местам = 33
- Фоновый квест — максимум 33: 4×1 + 3×3 + 3×5 = 28 (см. [[severfest-quest-mechanics|Механика квеста]]), __+5 за полный сбор банка__ (множитель ×2 из ранней версии отменён)
- Сюжетный квест — 20 (10 баллов за задание)
- Секретные письма — 17 (пока приблизительно, не финализировано)
- "Симпатия" организатора — 5, разово

### Дополнительные правила

- Слоты на вопросы ограничены первыми N на блок; N подбирается так, чтобы N × баллы ≥ числа людей на направлении.
- Оценка Alex для медианного участника: 51 балл за образование + 30 за развлечение = 81.
- Командная игра-проект идёт отдельно на каждом направлении, 20–60 человек на направление.

### Запланированное изменение командной игры

Разделить баллы на: (а) командное место и (б) личные номинации по игровой роли — лучший спикер, дизайнер, генератор идей, "спорщик", отстаивавший позицию, и т.д. Цель — чтобы участник не из команды-победителя тоже мог набрать сравнимо.

- Примерно 10 номинаций на направление
- Часть номинаций объявляется участникам, часть держится в тайне
- Кто подаёт номинацию — зависит от роли: жюри для спикера/дизайнера, кураторы команд/организаторы площадки — для процессных ролей

## Ранняя версия / мозгоштурм (v1, для истории)

Из исходного наброска банка заданий:

- Итого 28 баллов ("шмалей") за фоновый квест
- Правило: множитель ×2 за полный сбор банка

Это правило в v2 заменено на фиксированную надбавку +5 — стоит иметь в виду при чтении старых материалов (питч, исходный excalidraw-набросок), где ещё фигурирует ×2.

## Открытые вопросы

- Дисбаланс: награды за тайные задания (8–15 баллов каждая) потенциально перевешивают весь открытый квест.
- Судьба гибридной аукционной модели, где баллы работают как валюта — пока не увязана с остальной экономикой.
- Формат аукциона решён (классический на повышение + объединение баллов участниками), но количество лотов и порядок раскрытия — открыты.
- Не решено, участвуют ли баллы за тайные задания в каком-либо множителе.
- Экономика баллов вынесена как тема отдельной встречи (см. [[severfest-pitch|Питч начальству]]).
