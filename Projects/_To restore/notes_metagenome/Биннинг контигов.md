# Биннинг контигов

## Описание

Организация контигов, полученных от разных организмов, в бины — группы, предположительно принадлежащие одному геному/таксону. Использует информацию, не задействованную при сборке.

## Принцип работы

Контиги с одинаковыми признаками предположительно происходят из одного генома:

- __Глубина покрытия__ в одном образце
- __Профиль покрытия__ (паттерн обилия) по нескольким образцам
- __Тетрамерный состав__ (k-mer composition)

## Инструменты

| Инструмент | Алгоритм | Особенности |
|-----------|---------|------------|
| [[MetaBAT]] | Модифицированный k-medoid | Тетрамерное сходство + информация об обилии |
| [[CONCOCT]] | Gaussian mixture model | Обилие контигов + последовательный состав |
| [[VAMB]] | Variational autoencoder (нейросеть) | Контиги как точки в многомерном пространстве |
| [[MaxBin]] | Expectation-maximization | + mate-pair информация |
| [[Binnacle]] | — | + mate-pair информация, улучшение контигуальности |

## Выходные данные

- Бины контигов
- [[MAGs]] — бины, представляющие почти полные геномы

## Оценка качества

- Completeness (полнота)
- Contamination (контаминация)
