# Метагеномная сборка

## Описание

Процесс сборки ридов в контиги и MAGs обеспечивает более высокое разрешение геномного содержимого микробных сообществ по сравнению с анализом отдельных ридов и улучшает функциональную аннотацию.

## Основные алгоритмические подходы

### De Bruijn graph (short-read)

- Граф из k-меров, извлечённых из ридов
- Геномные повторы создают неоднозначности — основная проблема
- Большинство short-read ассемблеров используют этот подход
- Подробнее: [[de Bruijn graph]]

### Minimizers (long-read)

- Стратегия суммирования геномных данных в малом объёме памяти
- Преимущества скорости и памяти над de Bruijn graph
- Использует [[metaMDBG]]

## Инструменты

### Short-read ассемблеры

- [[MEGAHIT]] — ультрабыстрый, консервативный (более фрагментированные контиги)
- [[metaSPAdes]] — агрессивное сглаживание ошибок → более длинные контиги
- [[IDBA-UD]] — для неравномерного покрытия

### Long-read ассемблеры

- [[metaFlye]] — вычисляет частоты k-меров в локальном окружении для учёта неравномерного покрытия
- [[hifiasm-meta]] — для HiFi технологии PacBio, скорректированные критерии удаления химерных ридов
- [[metaMDBG]] — сборка на основе minimizers
- [[Canu]] — масштабируемая сборка long-read

### Гибридные ассемблеры

- [[Opera-MS]] — гибридный подход (в бенчмарке превзошёл другие по точности)
- [[hybridSPAdes]] — гибридный подход (в бенчмарке превзошёл другие по точности)
- [[Unicycler]] — превосходит MaSuRCA и SPAdes в сборке контигуальных геномов (Illumina + ONT)

### Специализированные

- __HCBHA__ — haplotype-resolved hierarchical clustering-based hybrid assembly для сложных экосистем (активный ил, сточные воды)

## Challenges

| Проблема | Описание |
|---------|----------|
| Неравномерное покрытие | Разная обилность организмов → разное покрытие контигов |
| Геномные повторы | Неоднозначность при реконструкции |
| Множественные штаммы | Multi-haplotype problem (NP-hard) |
| Ошибки секвенирования | Особенно критичны для long-read |
