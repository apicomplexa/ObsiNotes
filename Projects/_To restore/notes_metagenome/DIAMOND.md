# DIAMOND

## Описание
Инструмент для быстрого и чувствительного выравнивания белковых последовательностей, специально разработанный для short-read данных.

## Принцип работы
- Seed search подход
- Double indexing для ускорения поиска
- Поиск против NCBI, KEGG и других баз данных

## Входные данные
- FASTA последовательностей (нуклеотидные или белковые)

## Выходные данные
- Файлы выравниваний (табулярный формат, совместимый с BLAST)

## Применение
- Функциональное профилирование в eggNOG-mapper
- Таксономическое профилирование (высокие precision и recall для long-read без фильтрации)
