# HMMER

## Описание
Инструмент для поиска и выравнивания биологических последовательностей с использованием профильных скрытых марковских моделей (profile HMM).

## Применение
- Поиск белковых доменов (с [[Pfam]], [[InterProScan]])
- Функциональная аннотация микробных последовательностей
- [[KOfamKOALA]] использует HMMER/hmmbuild для KEGG-аннотации
