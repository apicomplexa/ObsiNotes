# Контаминация в метагеномике

## Описание

Контаминация — чужеродные ДНК-последовательности в метагеномных данных. Особенно критична для low-biomass образцов.

## Источники контаминации

- Лабораторная среда, оборудование, реагенты
- Исследователи
- Наборы и реагенты (небольшое количество контаминирующих бактерий, варьирует по производителям)
- Перекрёстная контаминация образцов (ДНК, индексы/баркоды, ампликоны)
- ДНК хозяина (особенно в low-biomass образцах: молоко до 95% хозяйской ДНК)

## Контроли для выявления

| Контроль | Описание |
|---------|----------|
| Field blank | Молекулярная вода вместо образца — выявляет контаминацию рабочего процесса |
| DNA extraction blank | Пустой контроль экстракции |
| No-template amplification | Контроль амплификации без матрицы |

## Вычислительные методы устранения

- [[Projects/_To restore/notes_metagenome/DeconSeq]] — удаление контаминирующих ридов
- [[KneadData]] — удаление ридов хозяина
- Алгоритмические модели: статистическое обнаружение контаминации через анализ частот ридов

## RIDE checklist

Рекомендации для снижения метагеномной контаминации:

- __R__eporting экспериментального дизайна
- __I__ncorporation негативных контролей
- __D__etermination уровня контаминации
- __E__valuation влияния контаминантных таксонов

## Low-biomass образцы

- Особая восприимчивость к контаминации
- Реагенты обрабатывать DNase перед использованием
- Примеры: воздух, кожа, лёгкие, кровь, моча, плацента
