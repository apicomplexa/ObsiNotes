# Референсные геномные базы данных

## Описание
Надёжность и робастность метагеномного анализа фундаментально зависят от полноты и точности референсных последовательностей в геномных базах данных.

## Основные базы данных

| База данных | Примерное число видов | Содержание |
|------------|----------------------|------------|
| [[RefSeq]] | 125,000 | Бактерии, вирусы, археи, грибы, эукариоты |
| [[Ensembl]] | 300,000 | Позвоночные, растения, грибы, бактерии, протисты |
| VEuPathDB | 500 | Эукариотические патогены |
| BV-BRC (PATRIC) | 87,000 | Бактериальные и вирусные патогены |
| [[UHGG]] | 204,000 | Кишечные прокариоты человека |
| HRGM | 232,000 | Кишечный микробиом человека (регистрация) |
| MBGD | 15,000 | Бактерии, археи, одноклеточные эукариоты (регистрация) |
| [[FungiDB]] | — | Грибковые референсные последовательности |
| JGI MycoCosm | 388 | Грибы и водоросли (регистрация) |
| [[GTDB]] | — | Геномно-основанная таксономия бактерий и архей |

## Проблемы несоответствия баз данных
- Разные базы могут показывать конфликтующие таксономические метки для идентичных видов/штаммов
- Некоторые виды уникально представлены только в одной базе
- Различия обновлений: GenBank (загрузки от submitters) vs RefSeq (регулярное курирование)

## Рекомендации
- Использовать наиболее полные и актуальные базы (RefSeq, GTDB)
- Не переключаться между базами в ходе одного проекта
- С осторожностью сравнивать результаты из разных баз
