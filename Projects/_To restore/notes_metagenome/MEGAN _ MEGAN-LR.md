# MEGAN / MEGAN-LR

## Описание
Инструмент анализа метагеномных данных. Использует BLAST для выравнивания и LCA (Lowest Common Ancestor) для таксономического присвоения. MEGAN-LR — адаптация для long-read ридов и контигов.

## Принцип работы
- Выравнивание каждого рида через BLAST к референсным геномам
- LCA подход: наименьший общий предок для всех геномов, к которым выравнивается рид
- Менее консервативные виды → ближе к «листьям»; более консервативные → ближе к «корню»

## Входные данные (MEGAN)
- BLAST alignment файлы

## Входные данные (MEGAN-LR)
- Long-read риды
- Контиги

## Выходные данные
- Таксономическое дерево с аннотированными ридами

## Применение
- Таксономический анализ метагеномных данных
- MEGAN-LR: high precision и recall без дополнительной фильтрации
