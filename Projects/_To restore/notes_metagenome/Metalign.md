# Metalign

## Описание
Эффективный гибридный метод alignment-based метагеномного профилирования через containment MinHash.

## Принцип работы
1. MinHash для оценки геномного сходства (подвыборки k-меров)
2. Оценка containment index — вероятность присутствия референсного генома в образце
3. Уменьшение размера референса → оптимизация процесса выравнивания
4. Финальное выравнивание для точного профилирования

## Применение
- Точное профилирование метагеномных датасетов при высокой эффективности
