# Metatag: 🦠Metagenomics — Расширение

## Краткое правило

Все заметки об анализе метагеномных данных — там, где в образце содержится много разной ДНК из разных организмов.

## Используй для

- Инструментов метагеномного анализа (вместе с `💻Bioinfo: tool`)
- Пайплайнов и подходов анализа метагеномных данных
- Концептов специфических для метагеномики
- Баз данных, специализированных для метагеномики

## Не используй для

- Генетических особенностей микроорганизмов (нет анализа сообщества)
- Общих методов секвенирования без контекста метагеномики

## Вторичные теги (расширенные)

| Тег                    | Описание                                       |
| ---------------------- | ---------------------------------------------- |
| `overview`             | Обзорные концепты метагеномики                 |
| `studyDesign`          | Дизайн метагеномных исследований               |
| `sampling`             | Сбор, хранение и обработка образцов            |
| `sequencing`           | Специфика секвенирования для метагеномики      |
| `preprocessing`        | QC и препроцессинг метагеномных данных         |
| `assembly`             | Метагеномная сборка                            |
| `binning`              | Биннинг контигов                               |
| `taxonomicProfiling`   | Таксономическая классификация и профилирование |
| `functionalAnnotation` | Функциональная аннотация метагенома            |
| `strainTracking`       | Штаммовый трекинг                              |
| `referenceDB`          | Референсные базы данных для метагеномики       |
| `dataDeposition`       | Депонирование и репозитории данных             |
| `reproducibility`      | Воспроизводимость исследований                 |
| `contamination`        | Контаминация и её контроль                     |
| `clinicalApplications` | Клинические применения                         |
