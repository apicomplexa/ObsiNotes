# CONCOCT

## Описание
Биннинг метагеномных контигов с использованием информации о покрытии и последовательностном составе в контексте Gaussian mixture model.

## Принцип работы
- Gaussian mixture model для идентификации кластеров/бинов
- Учитывает: обилие контигов + последовательностный состав

## Входные данные
- FASTA файлы контигов
- BAM файлы (покрытие по нескольким образцам)

## Выходные данные
- Бины контигов
