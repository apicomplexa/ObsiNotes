# metaHi-C

## Описание

Комбинация shotgun секвенирования и Hi-C (хромосомная конформационная иммунопреципитация) для метагеномных данных. Позволяет связывать геномные контиги из отдельных организмов через DNA-DNA proximity ligations.

## Принцип работы

1. Shotgun экстракция геномных фрагментов из микробного образца
2. Hi-C эксперимент: генерация DNA-DNA proximity ligations между локусами в пределах одной физической клетки
3. Связывание контигов, собранных из shotgun данных

## Входные данные

- Метагеномный образец (микробное сообщество)

## Выходные данные

- Связанные контиги с информацией о клеточной принадлежности
- Улучшенная сборка и биннинг MAGs

## Применение

- Снижение геномной фрагментации
- Улучшение [[Биннинг контигов|биннинга]]
- Связывание плазмид с бактериями-хозяевами

## Инструменты

- [[MetaCC]] — масштабируемый анализ как long-read, так и short-read metaHi-C данных
- [[HiCBin]] — биннинг контигов с использованием Hi-C контактных карт
