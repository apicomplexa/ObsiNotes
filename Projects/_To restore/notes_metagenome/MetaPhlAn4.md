# MetaPhlAn4

## Описание
Инструмент для профилирования микробных сообществ на основе клад-специфических маркерных генов. Версия 4 вводит поддержку кастомных баз данных из MAGs.

## Принцип работы
- Маркерные гены выбраны из >2 млн кандидатов: высокая консервативность внутри клады, минимальное сходство вне
- Нуклеотидное выравнивание ридов к клад-специфической базе маркерных генов
- Оценка обилия клад

## Новшества MetaPhlAn4
- Поддержка создания кастомных баз маркерных генов из MAGs
- Кастомные базы: комбинация маркеров из MAGs + референсных геномов
- Включение генетических данных неохарактеризованных таксонов

## Входные данные
- FASTQ/FASTA файлы метагеномных ридов

## Выходные данные
- Таксономический профиль с относительными обилиями

## Применение
- Профилирование микробных сообществ
- Связан с [[StrainPhlAn]] для штаммового анализа

## Ограничения
- Референс-зависимый: не выявляет полностью неизвестные организмы
