# MAGs (Metagenome-Assembled Genomes)

## Описание

Геномы или коллекции геномных фрагментов одного организма, полученные из метагеномного образца методом сборки и биннинга. Отличаются от геномов, реконструированных из культивируемых изолятов.

## Применение

- Геномная характеристика некультивируемых микроорганизмов
- Функциональная аннотация
- Расширение референсных баз данных (MetaPhlAn4 использует MAGs для создания кастомных баз маркерных генов)
- Более 20,000 reference mOTUs были идентифицированы из ~150,000 MAGs
