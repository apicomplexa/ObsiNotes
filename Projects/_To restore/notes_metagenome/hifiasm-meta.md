# hifiasm-meta

## Описание
Ассемблер метагеномов из высококачественных длинных ридов, адаптированный из hifiasm специально для HiFi технологии PacBio.

## Принцип работы
- Скорректированные критерии удаления коротких и химерных ридов для работы с потенциально низким покрытием некоторых геномов в образце

## Входные данные
- PacBio HiFi риды

## Выходные данные
- FASTA файлы контигов

## Применение
- Сборка метагеномов из PacBio HiFi данных
