# Маршрутизация бариатрических пациентов — MOC

> [!note] Черновой фронтматтер
> Заметки выгружены из чата claude.ai. Фронтматтер и теги временные — привести
> к конвенциям vault при раскладке.

Работа по ОЗЗ: полный маршрут пациента с ожирением, которому показано хирургическое
лечение, — от информирования до пожизненного наблюдения, — с обоснованием создания
единого центра бариатрии.

## Заметки

- [[bariatric-routing-document]] — содержание маршрута по этапам: отбор, очередь,
  обследование, операция, реабилитация, наблюдение. Основной клинико-организационный
  материал.
- [[bariatric-routing-center-argument]] — аргументация единого центра: типология
  потерь пациента, функции центра, показатели эффективности, тезисы для устного
  выступления.
- [[svg-diagram-pipeline-python]] — технический пайплайн генерации схем (Python → SVG).
  Переиспользуемо за пределами этой темы.

поглотил и расширил.

## Открытые вопросы

- **Требует проверки при раскладке:** тематически смыкается с линией маршрутизации
  пациентов в [[Семашко]] у [[kalinin]]. В самом чате эта связь не проговаривалась —
  проверить, не дублирует ли существующие заметки по ОЗЗ и не стоит ли вести как часть
  того же проекта.
- Генератор Word-документа (`build.js`, Node + библиотека `docx`, ~700 строк, весь текст
  разделов и таблиц) **утрачен** при сбросе рабочей среды. Восстановим, если понадобится
  править документ программно; пока правки — вручную в .docx.
- Нормативная база (перечни видов ВМП, предельные сроки ожидания) обновляется ежегодно.
  Перед использованием документа сверять с действующей редакцией ПГГ.
