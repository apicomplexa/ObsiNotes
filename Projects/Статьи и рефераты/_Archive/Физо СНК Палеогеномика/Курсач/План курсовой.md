# План доклада СНК кафедры Нормальной Физиологии по теме "Нобелевская премия по физиологии и медицине 2022 года"

- [x] ==Вступление. ==
	- [x] Цитата из пресс релиза нобелевского комитета о присуждении Сванте Паабо нобелевской премии по физиологии и медицине. (_Prize motivation: “for his discoveries concerning the genomes of extinct hominins and human evolution.”_)
	- [x] Введение в оперируемые понятия: геномика, палеогеномика, высокопроизводительное секвенирование второго поколения, сборка генома.
- [x] ==Краткая биография Сванте Паабо.==
	- [x] Рождение и семья.
	- [-] Египтология.
	- [-] "Уход" в молекулярную биологию, Защита докторской диссертации по молекулярной иммунологии.
	- [x] Смещение интересов в изучение древней ДНК. (совмещение ранних интересов египтологией и поздний - молекулярной биологией)
	- [x] Расшифровка генома неандертальца. Открытие денисовского человека.
	- [x] Нобелевская премия по физиологии и медицине.
- [x] ==Проблемы при изучении древней ДНК.==
	- [x] Деградация ДНК
		- [x] трансформация C→U
		- [x] Разрушение концевых нуклеотидов
		- [x] Оценки времени разрушения ДНК, до состояния непригодного к анализу (⇒ какие древние организмы можно изучить методами палеогеномики)
	- [x] Контаминация древней ДНК современной и средовой. Методы защиты
	- [-] Малые концентрации древней ДНК. 
- [x] ==Сборка древних геномов с опорой на современные и почему это необходимо в условиях господства NGS.==
- [x] ==Флагманские открытия в палеогеномике. (с 2010 по 2022)==
	- [x] Черновик генома неандертальцев (2010)
	- [x] Полный митохондриальный геном неизвестных гоминид из Южной Сибири. Доказательства ранней южноафриканской модели возникновения современного человека. Расширение ареала обитания Неандертальца
	- [x] Ядерный метагеном 3 гоминид с однократным прочтением.
	- [x] Ядерный индивидуальный геном неандертальца из Денисовой пещеры с высоким покрытием. 
		- [x]  Открытие Денисовского человека. Оценка вклада в генофонд современных людей
		- [x]  Разработка одноцепочечного метода подготовки библиотек секвенирования.
	- [x] Доказательства гибридизации между разными видами Homo
		- [x] Доказательства существования потомка скрещивания анатомически современного человека с неандертальцем в 6 поколении
		- [x] Обнаружение прямого потомка матери-Неандерталки и отца-Денисовца.
	- [-] Методики получение древней ДНК из осадочных пород. Возможность палеогенетически исследовать стоянки древних людей, не содержащих костных останков.
- [x] ==Вклад Неандертальцев и Денисовцев в геном современного человека.==
	- [x] Ионный канал Nav1.7 (кодируется геном SNC9A), отвечающий за передачу ощущения боли в периферической НС.
		- [x] Отличия в инактивационных воротах канала в неандертальской версии приводят к изменению пороговой чувствительности
		- [x] Распространённость неандертальской аллели в современной популяции
		- [x] Клиническая картина (нарастающая с возрастом вероятность хронических болей)
	- [/] Неандертальский аллель ппрогестеронового рецептора ассоциирован с риском преждевременных родов, но при этом снижает риск выкидыша
	- [-] Аллели Cyt-P450 схожие с обнаруженными у неандертальцев обуславливают меньшую эффективность ибупрофена
	- [-] Риск-фактор covid-19 ассоциированный с третьей хромосомой – схож с одним из неандертальских геномов. И находится на значитальном эволюционном расстоянии от "здоровых" гаплотипов
- [x] Заключение и выводы.
