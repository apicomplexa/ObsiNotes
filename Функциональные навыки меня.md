# Программирование и инфраструктура

## Языки и экосистемы

- Разработка скриптов и CLI-утилит на Python, R, Bash/Shell.
- Работа с экосистемой Python: numpy, pandas, polars, scipy, matplotlib, seaborn, biopython, scanpy.
- Работа с экосистемой R: tidyverse, data.table, ggplot2, Bioconductor, phyloseq, DESeq2, edgeR.
- Разработка воспроизводимых workflow для анализа омиксных данных.
- Написание модульного, документированного и тестируемого кода.
- Оптимизация производительности обработки больших наборов данных.

## Workflow orchestration и reproducibility

- Разработка пайплайнов на Snakemake, Nextflow
- Контейнеризация вычислительных окружений с Docker, Apptainer.
- Управление зависимостями через conda, pip, Bioconductor, CRAN, pixi.
- Создание репродуцируемых пайплайнов процессинга и анализа данных
- Подготовка lockfile и frozen environment.
- Управление версиями с Git.

## Linux, HPC и Cloud

- Работа в Linux environment.
- Понимание принципов основ HPC-кластеров и job scheduler: SLURM
- Мониторинг и оптимизация использования RAM, CPU, GPU, I/O.
- Работа с облачными платформами Google Colab
- Управление хранением больших объемов биологических данных.

## Форматы данных и инфраструктура хранения

- Работа с bioinformatics file formats: FASTQ, BAM/CRAM, SAM, VCF/BCF, GTF/GFF и др
- Индексация и компрессия файлов через bgzip, tabix, samtools.
- Организация metadata исследования и sample sheet.

# Анализ omics-данных

## Общие компетенции

- Контроль качества данных на всех этапах анализа.
- Интерпретация QC-метрик: depth, coverage, duplication rate, mapping rate, insert size, contamination.
- Подготовка данных к клинической интерпретации.
- Статистический анализ высокоразмерных биологических данных.

## NGS и геномика

- Анализ данных Illumina, ONT, PacBio.
- Alignment и pseudoalignment с bwa, bowtie2, STAR, salmon, kallisto.
- Variant calling для SNP, indel, SV, CNV.
- Анализ WGS, WES

## Transcriptomics

- Bulk RNA-seq, включая differential expression, isoform analysis, pathway enrichment.
- Gene set enrichment analysis с использованием GSEA.

## Эпигеномика

- ChIP-seq, ATAC-seq и DNA methylation analysis.
- Peak calling и motif analysis.
- Интеграция multi-omics datasets.

## Метагеномика и микробиом

- 16S/18S/ITS amplicon analysis.
- Построение таксономии с использованием SILVA, GTDB, Kraken2, MetaPhlAn.
- Функциональное профилирование
- Alpha/beta разнообразие

# Машинное обучение

- Использование AlphaFold, AlphaMissense, AlphaGenome, ESM, scGPT.

# Работа с биологическими базами данных

- Работа с публичными биологическими БД: NCBI, SRA, GEO, ENA, Ensembl, UniProt, PDB, GO, KEGG, Reactome, GTEx, TCGA.
- Автоматизированная загрузка и обработка данных через API.
- Интеграция внутренних и публичных датасетов.
