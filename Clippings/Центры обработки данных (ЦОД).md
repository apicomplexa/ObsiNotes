# Что такое ЦОД?

> [!$] ЦОД (Центр обработки данных)
> комплекс, обеспечивающий:
> - Бесперебойную работу цифровых сервисов
> - Безопасное хранение данных
> - Круглосуточную доступность информации

__Медицинская аналогия__: Если облачные сервисы (SaaS, PaaS, IaaS) — это "возможности цифровой медицины", то ЦОД — это "реанимация и операционный блок для данных".

# Ключевые компоненты ЦОД

| __Компонент__              | Роль в ЦОД                                 | Медицинская аналогия                                                |
| -------------------------- | ------------------------------------------ | ------------------------------------------------------------------- |
| __Серверы__                | Вычислительная мощность                    | Мозг - анализирует данные (например, расшифровывает ЭКГ)            |
| __Системы хранения __(СХД) | Хранение данных                            | Медицинская карта пациента - хранит историю болезней, снимки МРТ    |
| __Сетевая инфраструктура__ | Передача данных                            | Кровеносная система - обеспечивает связь между отделениями больницы |
| __Инженерные системы__     | Электроснабжение, охлаждение, безопасность | Вегетативная нервная система - поддерживает "жизнедеятельность"     |

# Критически важные аспекты для медицины

- __Надежность__ - отказ ЦОД = остановка работы отделения
- __Безопасность данных__ - защита медицинской тайны
- __Скорость передачи__ - быстрый доступ к тяжелым файлам (КТ, МРТ)
- __Соответствие стандартам__ - HIPAA, ФЗ-152, ГОСТ Р ИСО/МЭК 27001

# Примеры медицинских систем и требуемый уровень Tier

- Tier I: Научные базы данных, системы бронирования
- Tier II: Архивы изображений, системы управления ресурсами
- Tier III: Электронные медицинские карты (ЕМИАС), телемедицина
- Tier IV: Системы поддержки жизнедеятельности, диспетчерские скорой помощи

# Принцип резервирования

> [!$] Наличие одного резервного компонента сверх необходимого количества.

Пример: Если для охлаждения нужно чиллера (, то в системе будет чиллеров Если один выйдет из строя - остальные обеспечат работу.

_Медицинская аналогия:_ В операционной есть хирурга дежурный хирург на подстраховке.

# Практические выводы для врача

1. Облако = ЦОД - понимайте физическую основу цифровых сервисов
2. Надежность стоит денег - Tier IV дороже, но необходим для критичных систем
3. Безопасность данных - выбирайте провайдеров с медицинскими сертификатами
4. Планируйте отказоустойчивость - как в медицине, всегда должен быть "план Б"

# Ключевые термины

- __SLA__ (Service Level Agreement) - соглашение об уровне сервиса
- __Uptime__ - время бесперебойной работы
- __Отказоустойчивость__ - способность системы работать при отказах компонентов
- __HIPAA__ - международный стандарт защиты медицинских данных
