# Модель NIST — стандарт индустрии

Национальный институт стандартов и технологий США (NIST) разработал модель, определяющую 5 обязательных характеристик облачных вычислений. Эти характеристики являются своеобразным "дипломом" для любой облачной услуги.

# Ключевые характеристики облака

## 1. Самообслуживание по требованию (On-demand self-service)

> [!$] Потребитель может самостоятельно, без взаимодействия с персоналом провайдера, предоставлять себе вычислительные возможности (например, время сервера, сетевое хранилище) по мере необходимости.

- Медицинский пример: Врач-исследователь через веб-портал запускает сложный анализ геномных данных, просто нажав кнопку, не дожидаясь закупки и установки сервера IT-отделом.
- Связь с курсом: Реализуется через модели [[Основные понятия в области облачных технологий|PaaS и SaaS]].

## 2. Универсальный доступ по сети (Broad network access)

> [!$] Возможности облака доступны по сети через стандартные механизмы (браузеры, приложения) и могут быть использованы с различных клиентских платформ (ПК, смартфоны, планшеты).

- Медицинский пример: Хирург получает доступ к архиву медицинских изображений (PACS) со своего планшета во время консилиума; врач просматривает историю болезни пациента с домашнего компьютера.
- Связь с курсом: Прямое следствие [[Сервис-ориентированная архитектура (SOA) в медицине|SOA]]

## 3. Пулинг ресурсов (Resource pooling)

> [!$] Поставщик услуг объединяет вычислительные ресурсы в единый пул для многопользовательского обслуживания (мультитенантность). Ресурсы динамически назначаются и переназначаются потребителям, которые обычно не знают точного местоположения этих ресурсов.

- Медицинский пример: Данные пациентов из сотен разных поликлиник хранятся и обрабатываются в одном облаке провайдера, но при этом надежно изолированы друг от друга (аналогия: жильцы многоквартирного дома).
- Связь с курсом: Физическая основа — [[Центры обработки данных (ЦОД)|ЦОД]]; логическая организация — [[Сервис-ориентированная архитектура (SOA) в медицине|SOA]] и [[Распределенная архитектура]]

## 4. Эластичность (Rapid elasticity)

> [!$] Возможности могут быть эластично предоставлены и освобождены (в некоторых случаях автоматически) для быстрого масштабирования в соответствии со спросом. Для потребителя возможности часто кажутся безграничными.

- Медицинский пример: Во время пандемии телемедицинская платформа автоматически получает дополнительные вычислительные мощности для обработки возросшего числа консультаций, а после спада нагрузки — "сжимается".
- Связь с курсом: Главное преимущество, вытекающее из пулинга ресурсов и [[Распределенная архитектура]]

## Учет потребления (Measured service)

> [!$] Использование облачных ресурсов автоматически отслеживается, контролируется и оптимизируется. Потребитель платит только за те ресурсы, которые он фактически использовал (модель "pay-as-you-go")

- Медицинский пример: Больница получает детализированный счет за облачный сервис: "Хранение 150 ТБ данных: X рублей. Вычисления для научного проекта: Y рублей".
- Связь с курсом: Замыкает экономический цикл, ставший возможным благодаря всем предыдущим характеристикам.

# Финальный синтез: облако как система

Все пять характеристик взаимосвязаны и работают как единый механизм:

- Пулинг ресурсов (3) и Учет потребления (5) являются экономическим фундаментом.
- Благодаря им становится возможным Самообслуживание по требованию (1).
- Универсальный доступ по сети (2) и Эластичность (4) делают эту модель удобной и мощной для конечного пользователя (врача).  

> [!$]Итог
> Облако — это не одна технология, а комплексная модель, обладающая этим набором свойств.

# Ключевые термины и определения

- __NIST__ (National Institute of Standards and Technology) — Национальный институт стандартов и технологий США.
- __Мультитенантность__ (Multi-tenancy) — архитектура, при которой единый экземпляр программного приложения обслуживает множество клиентов ("арендаторов").
- __Pay-as-you-go__ — модель оплаты "по факту использования", авансовая оплата не требуется.
