# Описание

Этап с наибольшим вкладом в вариабельность результатов исследования среди всех этапов пробоподготовки. Включает лизис клеток и выделение/очистку ДНК.

## Принцип работы

1. Лизис микробных клеток (физический или ферментативный)
2. Выделение ДНК
3. Очистка от ингибиторов ферментов

## Методы лизиса

| Метод | Применение | Ограничения |
|-------|-----------|-------------|
| __Bead-beating__ | Short-read секвенирование | Фрагментация ДНК (не подходит для long-read) |
| __Ферментативный лизис__ | Long-read секвенирование | Нерешённые проблемы с лизисом грибных клеток |

> Bead-beating рекомендован для эффективного лизиса грамположительных бактерий и грибных клеток при short-read анализе

## Коммерческие методы

- Фенол-хлороформная экстракция
- CTAB-экстракция
- Коммерческие киты (бенчмаркинг проводился для разных типов образцов)

## Контроль качества

- __Field blank__ (молекулярная вода вместо образца) — для выявления контаминации
- __Позитивные контроли__ (mock community) — для выявления смещений
- __Внутренние стандарты__ (экзогенная ДНК/РНК) — для нормализации

## Ограничения

- Нет единого оптимального протокола для всех типов образцов
- Разные методы дают разные микробные профили
- Организмы с прочными клеточными стенками могут быть недопредставлены
