# Pfam

## Описание
База данных белковых семейств, используемая для аннотации функций на основе консервативных доменов.

## Применение
- Идентификация белков со связанными функциями
- Выявление консервативных регионов для предсказания функций на протеомном уровне
- Используется с [[HMMER]] для поиска доменов
