# De Bruijn graph

## Описание

Структура данных, используемая в геномике для представления перекрытий между последовательностями. Основа большинства short-read метагеномных ассемблеров.

## Принцип работы

- __Узлы__: k-меры (подстроки длины k)
- __Рёбра__: перекрытия k-1 оснований между последовательными k-мерами
- Последовательность генома "читается" обходом графа с конкатенацией k-меров

## Применение в метагеномике

- k-меры извлекаются из всех ридов образца
- Граф отражает структуру всех геномов в образце одновременно
- Использование нескольких размеров k-меров: короткие k-меры → устойчивость к ошибкам секвенирования; длинные k-меры → разрешение повторов

## Ограничения

- Геномные повторы создают неоднозначности в графе
- Неравномерное покрытие в метагеномике усложняет детекцию повторов
- Высокие требования к памяти для больших k
