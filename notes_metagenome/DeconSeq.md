# DeconSeq

## Описание
Автоматизированный инструмент деконтаминации для удаления ридов хозяина и других нежелательных источников из метагеномных данных.

## Применение
- Удаление ридов генома хозяина
- Деконтаминация метагеномных образцов

## Входные данные
- FASTQ файлы

## Выходные данные
- Очищенные FASTQ файлы
