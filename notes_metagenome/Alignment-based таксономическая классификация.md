# Выравнивание-based таксономическая классификация

## Описание

Методы выравнивания ридов к референсным геномам или маркерным генам для таксономической классификации. Более чувствительны, чем alignment-free методы, но вычислительно затратнее.

## Подходы

### Полные референсные геномы

- Выравнивание всех ридов к полным геномам
- Пример: [[MEGAN]] — использует BLAST, присваивает LCA

### Маркерные гены

- Уменьшенная база данных только из маркерных генов
- Пример: сокращение RefSeq (9.8 TB) → MetaPhlAn база (10.41 GB) = снижение на 98.95%
- Маркерные гены: консервативные однокопийные гены с уникальным представлением таксонов

| Инструмент | Особенности |

| [[MEGAN-LR]] | Адаптация для long-read и контигов |
