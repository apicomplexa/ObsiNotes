# k-mer таксономическая классификация

## Описание
Alignment-free методы для таксономической классификации. Менее вычислительно затратны, чем alignment-based методы.

## Принцип работы
1. Генерация k-меров из метагеномных данных
2. Сравнение с k-мерами референсных баз данных
3. Идентификация совпадающих k-меров
4. Квантификация → таксономический профиль

## Подходы

### Точное k-mer matching
- Сопоставление k-меров запроса с референсными k-мерами
- LCA геномов, содержащих данный k-мер → таксономическое присвоение
- Пример: [[Kraken]]

### k-mer sketching (скетчинг)
- Конденсирование больших датасетов в «сигнатуры» при сохранении отношений сходства
- Сокращение вычислительных ресурсов
- Примеры: [[sourmash]], [[Mash Screen]]

### Discriminative subsets
- [[YACHT]] — ANI-based статистический тест

## Инструменты

| Инструмент | Подход | Особенности |
|-----------|--------|------------|
| [[Kraken]] | Exact matching + majority vote | Ultrafast; проблемы с точностью на низких таксономических уровнях |
| [[Bracken]] | Вероятностное переназначение ридов | Улучшение точности Kraken на fine resolution |
| [[sourmash]] | MinHash sketching | Высокие precision и recall без фильтрации |
| [[Mash Screen]] | MinHash | Оценка containment index |
| [[YACHT]] | ANI-based | Статистический тест наличия/отсутствия |
