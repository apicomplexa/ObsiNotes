# Дизайн метагеномного исследования

## Описание

Строгий дизайн исследования максимизирует потенциал получения воспроизводимых данных и обеспечивает научную обоснованность выводов. Дизайн должен соответствовать конкретным исследовательским целям.

## Типы дизайнов

| Тип | Описание | Применение |
|-----|----------|------------|
| __Обсервационное__ | Мониторинг без вмешательства | Изучение естественных вариаций микробиома |
| __Cross-sectional__ | Срез в один момент времени | Поиск ассоциаций микробиома с исходами |
| __Case-control__ | Сравнение больных и здоровых | Выявление связанных с болезнью различий |
| __Longitudinal__ | Отслеживание изменений во времени | Динамика микробиома, временны́е паттерны |
| __RCT__ | Рандомизированное контролируемое испытание | Оценка причинно-следственных эффектов вмешательств |

## Расчёт размера выборки

Необходим для обеспечения достаточной статистической мощности. Проводится через __power analysis__ с использованием оценок effect size из пилотных исследований или литературы.
